# cw-trainer v1.3.2

日期：2026-08-28

## 修复

- **电键页第二行文字底部被裁**，`Q` 看起来像 `O`。解码文本用的是
  `UI_FONT_MID`（行高 37），两行需要 74px，而容器只给了 60px——第二行的下缘
  被裁掉 14px，`Q` 的尾巴正好落在那里。

  重排了这一页的纵向预算（顶栏之下 212px）：解码文本 74 / 点划 26 / 电键 108。
  点划那行改用 `UI_FONT_CN`（行高 26）让位——它是转瞬即逝的提示，而解码文本
  是要读的；电键区 108px 仍远超 44px 的触控下限。

  这和配网页输入框、对练页状态带是同一类问题：**容器高度必须 ≥ 内容行高**。

## 改动

- 固件升级页改为「当前版本 / 最新版本」两行平行标注，不再写「服务器 vX」。
  用户关心的是最新的是哪个，服务器只是它碰巧待的地方。
