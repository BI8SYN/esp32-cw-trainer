整机换了一套视觉语言：**纸底墨字、压印质感、一个铜色 accent**。顺带把交互补上了声音。

设计记录：
- `docs/design/cw-trainer-visual-direction.html`（视觉方向、token、真机实测与十一轮校正）
- `docs/superpowers/specs/2026-09-01-cw-trainer-ui-sound-design.md`（交互音效）

## 视觉

### 从灰阶换成纸面

之前是刻意的零装饰灰阶版（白底黑字 + 两级灰）。现在是纸底 `#EDE1C8`、墨字
`#2A2118`、唯一的 accent 铜色 `#945418`。**所有值都按 RGB565 量化后重算过对比度**，
表里的数字是屏上真会出现的，不是设计稿上的。

**没有一处渐变。** 素材样机实测：这块屏连离线 Floyd–Steinberg 抖动过的渐变都有可见
台阶。于是立体感全部由 1px 的高光/暗线浮雕承担，质感由平铺噪点承担。

这不是退让——电报房本来就该是压印质感，纸、铅字、黄铜刻痕的立体感本来就来自边缘
明暗，不来自表面高光。**硬件的限制和风格的方向这次是同一个方向。**

### 三档深度，每一档编码一件事

**井（凹）装内容、页面（平）是纸本身、控件（凸）可以按。**

对练页和电键页现在版式完全一致（像素实测两页的井边沿分毫不差）——两页铺的是同一组
电键，用户来回切时不该重新找东西在哪。

### 中文终于有了第二级字号

在此之前中文只有一级（行高 26）：`font28` 和 `EN_BIG` 都不含中文字形，代码里到处是
「含中文必须留在 `UI_FONT_CN`」的注释，中文文案之间做不出大小对比。

新增 28px 思源宋（OFL 许可）。选宋体而不是黑体是方案定的「标题宋体 + 正文黑体」，
28px 撑得住宋体的横细竖粗，20px 正文留黑体保小字可读。

**`fonts/` 下第一个有源可重生成的字体**——其余三个都是第三方工具产物、仓库里没有源
字体，这也正是 `tools/subset_font.py` 只能做 C→C 裁剪的原因。

### 电键桨改成黄铜

全工程唯一做「真材质」的地方，因为它是唯一一个屏幕元素直接对应用户手上真实物件的
页面。平涂 + 细颗粒 + 2px 浮雕，按下时整块压暗。

桨上的「点」「划」由汉字改成图形，**长度比 1:3 就是莫尔斯的定义本身**——画出来就把
这条规则摆在了桨上，而两个汉字一点都不携带这个信息。

## 新增

### 交互提示音

判对 / 判错 / 课次解锁 / 导航点击 / 异常，跟随音量，可在**设置 → 音频 → 提示音**
关掉（默认开）。

这台机器只有一个振荡器，四个生产者共用，所以**任何提示音在受过训练的耳朵里都会被
听成莫尔斯**。因此提示音刻意做成「不是莫尔斯」：20ms 短于 40 WPM 的点（30ms），且
序列内频率在变——而莫尔斯从不变频。频率取侧音的倍数，改音调时相对关系不变。

仲裁放在 `tone_gen` 里，而不是让 UI 层去问三个模块 `is_busy()`——**把仲裁放在被抢的
资源上**，四个生产者继续互不认识。两层判忙闲缺一不可：`cw_player` 在整个播放会话期间
占住（光靠「安静了多久」是错的，听写在字符之间本来就有长静音，提示音会正好落进字
间隔），加 150ms 静音门闩管侧音和收报。被占用**整段丢弃不排队**。

**未达标刻意静音**：Koch 的前提就是错着学，给常态配失败音等于几十次惩罚。

## 修复

### 联网对练里本机发报不记词间隔

`on_key_char()` 里 `if (c == ' ') return;`——不发网络包是对的（KOB 协议里词间隔靠时序
表达），但它连**本机日志**也一起跳过了。于是同一个人发同样的报，电键页有空格、对练
页没有。

### 收报区第一条消息上方多一条白线

`ui_bevel()` 塞进去的子对象被 flex 容器当成了第一个布局成员。加
`LV_OBJ_FLAG_FLOATING`——它同时解决不参与布局和不跟随滚动两件事（浮雕画在井壁上，
不该跟着内容滚走）。

### 顶栏的返回键和 wire 选择器贴死上下边缘

根因是**顶栏高度一直没按计划改**：设计文档里「28 → 32」写了很久但只写在纸上，而
`UI_FONT_CN` 的行高就是 26，28px 的栏里放不下任何带内边距的控件。落地 32px，并新增
共享控件 `ui_chip()`，顶栏里所有的键都改用它。

顺带修掉一个先前就存在的坑：那几个顶栏按钮被写死成高 **24**，比 26 的行高还矮——
内容比容器高会被 LVGL 当溢出处理，文字下偏还会打开滚动。

### 设置页新加的项永远不会显示

`GROUP_N` 是手写的 `{ 4, 2, 10, 4 }`，往 `AUDIO[]` 加第 5 项之后计数还是 4，**多出来
的那一项永远不渲染而且编译毫无怨言**。改成由数组自己算。

### 设置升到 version 4

加 `sound_on` 必须升版本。v1/v2/v3 的 `sizeof` 恰好都是 68，v4 是 72——**v4 是第一个
长度和前面不同的版本**，但判据仍然只看 `version` 字段。

**老设备升级上来 Koch 进度不丢**，提示音默认开。

## 改动

- **OTA 单槽余量 234 KB → 344 KB。** 标题字体只用在一处（首页「KOCH 第 N 课」）却背着
  完整的 368 字形、123 KB。LVGL 8.3 的 `lv_font_t` 支持 fallback，接到 `font20` 之后
  缺字的失败模式从「空白」变成「退成 20px」——字号不对但看得见。而
  `check_charset.py` 已经保证 `font20` 覆盖全部界面文案，两条合起来是硬保证：
  **标题字体想裁多小都不可能渲染成空白**。裁到 17 个字形，123 KB → 8.6 KB。
- 首页 Koch 卡片不再整块可点，右下角是一个真按钮。卡片不可点了就不该再是凸起的——
  凸起在这套语言里编码「能按」。
- 设置列表加常显滚动条（常规组 10 项共 420px 塞进 208px 的框，早就需要滚了）。
- 「恢复出厂设置」终于是红的。此前它和「屏幕亮度」长得一模一样，有二次确认但界面上
  没有任何视觉警示。

## 开发工具（不影响固件）

- **画面指纹巡检**（`-DCW_SCREENSHOT=ON`）：在 `flush_cb` 上串钩子，对真正送进屏幕的
  像素算指纹。每次跑两遍——两遍一致的页面才有资格参与比对，这把尺子的可信度是它自己
  证明的。这一版里它逮到了「设置项永远不显示」和「NVS 迁移是否保住了 Koch 进度」。
- **导图模式**（`-DCW_SCREENSHOT_DUMP=ON`）：把像素 base64 出串口，主机拼回 PNG。
  指纹只回答「变了没有」，回答不了「变得对不对」。
- **色板检查**（`tools/check_palette.py`）：RGB565 量化撞车 + 正文对比度。补它是因为
  `UI_HILITE` 和 `UI_RAISE` 曾经量化到同一个值，**凸起按钮的高光边整条消失**，而这个
  错误编译不报、指纹只说「变了」、看缩略图也看不出来。
- **远程烧录**（`tools/flash_remote.sh`）：本机编译、远端只推串口，串口自动探测。

## 验证

- 主机测试 **14 个程序**全过。新增 `test_tone_seq.c` 6 条——**其中一条当场逼出了一个
  真实的设计错误**：异常音最初是单频 120ms，而 30 WPM 的划正好是 120ms，它会被听成
  字母 T。规则写在 spec 里，但只有把它变成断言才发现自己的表里有一行不守规则。
- 10 个页面指纹两遍自稳、无崩溃。
- 视觉经过**十一轮真机校正**，全部记在 `docs/design/cw-trainer-visual-direction.html`
  里，包括每一次「设计稿上对、真机上错」的原因。
- 设置 v3 → v4 迁移实测：日志出现 `migrating config v3 -> v4`，而主页指纹一个像素没变
  ——主页显示的正是当前课次和上次正确率，指纹不变即进度完好。

## 已知问题

- **交互提示音的仲裁行为没有人听过。** 序列的构造有主机测试，但「提示音会不会落进
  听写的字间隔」「按电键时是否立即让位」「功放冷启动第一声破不破」「像不像莫尔斯」
  这四条只有耳朵能验，已记进 `firmware/cw-trainer/README.md` 的未验证清单。
- 联网对练页评审出的九条问题（本机发报没有前缀、状态带空闲时空白、服务器连不上时没有
  出口等）已查证并记入 `docs/optimization-backlog.md`，本版确认接受、不做。
- 电键页在音频异常时会多出一条通知条压住点划行。既有问题，与本次改动无关。
