# cw-trainer v1.5.0

日期：2026-08-28

真机对练测出来的一批问题。前三条是同一个根子：**音频和文字走的是两条互不相干
的时间线**，而收报缓冲是按墙上时钟推进的。

## 修复

### 一、声音比文字晚半秒到一秒

`on_code()` 里，音频排进抖动缓冲（`rx_delay_ms` 默认 500ms 后才起播，再花掉这个
字符自己的时长），文字却立刻推给界面、100ms 内就显示。**文字恒定领先声音
0.5~1 秒**——这不是抖动，是设计上就没对齐，看着的和听着的根本不是一个字。

修法：让文字跟着音频走。`kob_rxbuf` 在每个码包（协议上就是一个字符）末尾埋一个
边界标记，播完最后一个码元才计数；`kob_net` 维护一条同样长度的待播文字队列，
播完第 N 个字符才放出第 N 条文字。

标记取 `INT32_MIN`：真实码元是毫秒时长，正数闭合、负数断开，而 `1`/`2` 已被锁存
占用、`0` 是填充位，一个负到 24 天的「断开」不可能出现在真实数据里。

丢包的 `?` 并进下一个字符的文字，不单独排一条——丢掉的包没有音频，单独排队就
永远等不到「播完」，会把整个队列堵死。

### 二、本机发报时，对方发来的完全没有声音

原来只是「不调 `tone_gen_set()`」，而缓冲照常按墙上时钟推进——你按键这几秒里
对方的码元全都流过去了，松手时那几个字**永远听不到**。

修法：不是跳过，是**冻结**。发报期间停住时间基准，松手后按冻结时长整体后移，
接着播。侧音只有一路，本来就不能同时响两个人，但内容不该丢。

判据不能用 `s_st.i_am_sending`：它跟的是键的按下/抬起，而一个字符里键大部分时间
是抬起的，那样会在每个点划的间隙里放对方半个码元，糊成一片。改用 `tx_busy()`
——最后一个边沿之后静默满 1 秒才算这一轮发完（20 WPM 下字间隔 180ms、词间隔
420ms，都在 1 秒内，一整段发报不会被误判）。

### 三、交替发报时记录被劈成碎行

原来是一块 `char[512]`，规则是「换人就换行」，而 CW 一个字符一个包——你发一个、
对方插一个、你再发一个就是三行，自己连发的一串被劈开了。

记录改成结构化的若干条，每条属于一个发报方，追加只动那一条。规则仍然是**换人
就换行**（一行 = 一个人连着发的一段）：中途试过「往回找同一个人那条接上去」，
各自的字确实聚在了一起，但新来的字会插进屏幕上早就滚过去的那一行，看着莫名
其妙。

### 四、按住一块桨滑到另一块，还是原来那一块

LVGL 在手指按下的那一刻就把「被按对象」锁定了：之后滑到另一块，第二块收不到
任何事件，第一块继续收 `LV_EVENT_PRESSING`。只认 `PRESSED` 的话，滑过去仍然在
发原来那个符号。

改成每次 `PRESSING` 都按手指的实时坐标重新判断在哪一半，跨界就松开旧的、按下
新的。触摸桨只有一根手指，滑动等于快速换手。

## 改动

### 收报区：更高、能滚、看得出能滚

- 高度从 74（两行）提到 100（约三行）。整页 240 是死的，只能从电键让。
- 自动滚到底改成**只在本来就贴着底部时才滚**。原来无条件 `scroll_to_y`，你手动
  往上翻记录，下一个字一到就被拽回去，等于翻不了。
- 滚动条**常显**而不是 AUTO：AUTO 只在滚动过程中出现，对「让人知道下面还有内容」
  毫无帮助。样式要自己写——`lv_obj_remove_style_all()` 把默认样式连滚动条一起
  去掉了，只设 mode 是画不出来的。
- 历史容量从 512 字节改成 32 条记录，**点收报区弹出全屏历史**（约 8 行）。

历史做成遮罩而不是独立页面：换页会走 `ui_nav_show()`，对练页的 `on_delete`
一触发就 `kob_net_stop()`，看一眼历史等于把线路断了再连回来。

### 呼号牌：深底浅字，且不等音频

呼号原来只是行首几个字符，和内容一个颜色一样大小，扫一眼分不出谁是谁。改成
黑底白字的牌子。LVGL 的 label 做不到分段背景（recolor 和 span 都只能改文字
颜色），所以每条记录拆成独立的行控件：呼号牌 + 自动折行的内容。

代价是要自己维护「控件和记录一一对应」，**不能每来一个字符就全量重建**——20 WPM
下每秒十几个字符，32 行 × 2 个对象重建十几次，ESP32 上是实打实的开销。所以只有
结构变化才动控件，往已有的一条里追加字符只 `set_text` 那一个 label。

牌子还不能等音频：文字现在跟着声音走，要慢半秒到一秒，而「谁在发」是收到包那
一刻就确定的事。`kob_net` 在一轮发报的第一个包到达时推一条**空内容**的记录，
界面见到就只起一条把牌子亮出来，内容随后一个字一个字填进去。

### 电键高度全局统一

电键页 108、对练页 84，同一双手在两页之间切换，按的位置却不一样。抽成
`UI_PADDLE_H = 84` 由两页共用；对练页的收报区高度改成由它反推，不会再各自漂。

连带修了电键页外接模式的越界：那两个指示块是按 `py = 132` 写死的（`py+44`、
高 60），电键区下移之后变成 260，顶出屏幕。改成跟着可用高度算。
