### SD 卡（HSPI，预留）

> **18 和 23 已被外接电键占用**（IO18 = 点，IO23 = 划，见
> `README.md`「外接电键接线」）。选它们正是因为在 SD 方案里它们
> 是 ESP32 往外送的输出、板上没有器件驱动，用作输入最干净。将来真要做 SD 卡功能，
> 这两根要重新分配——CN4 的 IO35 是唯一不碰 SD 总线的候选，但它没有内部上下拉，
> 需要外接电阻。

| 信号 | GPIO |
|---|---|
| SD_MOSI | 23 |
| SD_MISO | 19 |
| SD_SCK | 18 |
| SD_CS | 5 |

## 接口

| 接口 | 位置 | 座子规格 | 说明 |
|---|---|---|---|
| USB Type-C | 侧边 | — | 5V 供电 + CH340 串口下载 |
| 串口 | 背面 CN2 | 1.25mm 4P（厂商文档标注） | UART 调试（UART/GND/TXD/RXD），随板附一条 1.25 转 4P 杜邦线 |
| 电池口 | 背面 CN5 | 1.25mm 2P（厂商文档标注） | **左正右负**，3.3V 输入；严禁反接或接 5V |
| 音频口 | 正面 CN1 | 2.0mm（厂商文档只写「2.0P」） | 音频输出（配合 GPIO26 DAC + GPIO4 使能） |
| 外置扩展口 | CN3 | 1.25mm **4P**，和 CN2 同一颗料 | IO27(CS) / IO18(SCK) / IO19(MISO) / IO23(MOSI) |
| 扩展口 | CN4 | 1.25mm **4P**，和 CN2 同一颗料 | GND / （空脚）/ IO35 / 3.3V |
| TF 卡座 | 正面 TF1 | — | MicroSD |
| BOOT / RESET | SW1 / SW2 | — | 板载按键 |

> 厂商文档（`docs/vendor-manual.md` 第 7 节）只给 CN1/CN2/CN5 标了规格，CN3/CN4 只写
> 功能和丝印。CN3/CN4 的规格是从厂商接口图量出来的：三个座子的胶壳宽度完全一致
> （83 / 83 / 82 px @ 7.7 px/mm），针数也一致，**就是和 CN2 同一颗 1.25mm 4P**。
> CN5（2P）比它们窄 18 px ≈ 2.5mm = 两个 1.25 节距，几何自洽；CN1 比 CN5 宽 5 px
> ≈ 0.75mm = 1.25→2.0 的节距差，印证厂商标的「2.0P」。
>
> **CN3 只有 4 针，丝印上没有 IO22。** 早期文档把 CN3 记成 5P、末位多一个 IO22，是
> 从 PDF 转录时看错了——cw-trainer v1.3 之前那句「接 CN3 的 IO22」根本无法执行。
>
> 五个座子没有一个是 2.54 排针，接外设只能用 1.25mm（CN2/3/4/5）或 2.0mm（CN1）端子线。

### 配套端子线怎么买

板上五个座子只有两种规格，按这两条搜就够了：

| 要接的口 | 搜索词 | 说明 |
|---|---|---|
| CN2 / CN3 / CN4 | `1.25mm 端子线 4P 单头` 或 `MX1.25 4P 单头电子线` | 同一颗料，一种线通吃 |
| CN5（电池） | `1.25mm 端子线 2P 单头` | 注意左正右负 |
| CN1（音频） | `PH2.0 端子线 2P 单头` | JST PH 系列就是 2.0mm |

- 「单头」= 一端压好端子、另一端是裸线（或杜邦头），正是接外设要的形态。成品线
  十条几块钱，比买散胶壳 + 簧片 + 压线钳（SN-01BM 之类）划算得多。
- 1.25mm 这个节距有两个互不通用的家族：JST **GH1.25**（带卡扣）和 Molex
  **MX1.25 / PicoBlade**（无卡扣）。CYD 这类板子普遍用后者。
  **最省事的验证：把随板附的那条「1.25 转 4P 杜邦线」插进 CN3 试一下**——CN2/CN3/CN4
  是同一颗料，能插上就照那条线的规格买。
- 卡尺自检：4P 座子最外两针中心距 = 1.25 × 3 = **3.75mm**；CN1 两针中心距 = **2.0mm**。
- 别买 XH2.54 或 2.54 排针母头，节距差一倍，插不进。
- 做外接电键要 CN3（信号）+ CN4（地）各一条，所以 **1.25mm 4P 线至少买两条**。

## 本机改装

盒子内部除开发板外还加了（见 `IMG_1302.jpeg`）：

- 18650 锂电池 1 节
- 升压/充放电模块（板上有 1R0 电感，输出接到开发板电池口）
- 绿色 3D 打印外壳，侧面开有拨动开关孔位
- **蜂鸣器接在 GPIO27 上**。这条线因此不能再当输入用——它的空闲电平恒为低，
  cw-trainer 早期把外接电键的「划」接在这里，一启用就是「划桨一直按着」。
  仓库里一度推测原因是板载扩展 SPI 片选的外部偏置在拉，那个推测是错的。

## 注意事项

- GPIO34 / 36 / 39 为**仅输入**引脚，不能做输出。
- 屏幕若红蓝反色，检查 ST7789 的 BGR/RGB 初始化位。
- 屏幕旋转或坐标方向改变后需要重新做触摸校准。
- 板卡逻辑 3.3V，勿直接接 5V 信号。
