这版要验证什么

  • 进来就有 BOT 在呼叫，不需要先想「第一步干什么」
  • 状态带永远回答「现在什么情况」——空闲说该你了，对方发时说谁在发，我发时实时回显
  • 收报区是双方对话记录，我发过的能回头看
  • 电键在对方发报时不禁用，按下即打断（CW 的正常交互）
  • WiFi 失败和服务器不可达分开报，处理方式不同
  • 丢包的字符显示 ?，不静默吞掉

在设备上按 dit / dah 可以试发报，松开后会落进记录。
